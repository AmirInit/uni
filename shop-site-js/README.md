# بازارک — فروشگاه آنلاین | Bazarak — Persian E-Commerce Store

<div align="right">

یک فروشگاه اینترنتی کامل و راست‌به‌چپ (RTL) که با **React + Vite** در سمت کاربر و
**Node.js + Express + SQLite** در سمت سرور ساخته شده است. تمام رابط کاربری فارسی است،
اعداد با ارقام فارسی نمایش داده می‌شوند و پایگاه داده یک فایل ساده است — بنابراین برای
اجرای پروژه به نصب هیچ پایگاه دادهٔ جداگانه‌ای نیاز ندارید.

</div>

A complete right-to-left (RTL) Persian e-commerce application: **React + Vite** on the
front end, **Node.js + Express + SQLite** on the back end. The entire UI is in Persian,
all numbers render in Persian digits, and the database is a single file — no separate
database server to install.

---

## ⚡ اجرای سریع | Quick Start

```bash
npm install     # ۱. نصب وابستگی‌های سرور و کلاینت با هم
npm run seed    # ۲. ساخت جداول + افزودن حساب‌ها و ۲۲ محصول نمونه
npm run dev     # ۳. اجرای هم‌زمان بک‌اند و فرانت‌اند
```

سپس مرورگر را باز کنید | Then open your browser at:

### 👉 **http://localhost:5173**

> این پروژه از **npm workspaces** استفاده می‌کند، بنابراین یک بار `npm install` در پوشهٔ
> اصلی، وابستگی‌های `server/` و `client/` را با هم نصب می‌کند.
>
> This project uses **npm workspaces**, so a single `npm install` at the root installs
> dependencies for both `server/` and `client/`.

## 📋 پیش‌نیازها | Prerequisites

| مورد / Requirement | نسخه / Version                                  |
| ------------------ | ----------------------------------------------- |
| **Node.js**        | `20.19` یا بالاتر (پیشنهاد: نسخهٔ LTS جاری)      |
| **npm**            | `10` یا بالاتر (همراه Node.js نصب می‌شود)        |
| پایگاه داده        | ❌ هیچ‌چیز — SQLite داخل پروژه است               |

بررسی نسخه | Check your version:

```bash
node --version   # باید v20.19.0 یا بالاتر باشد
npm --version
```

> **دربارهٔ SQLite:** پایگاه داده یک فایل معمولی در مسیر `server/data/shop.db` است که
> با اجرای `npm run seed` ساخته می‌شود. کتابخانهٔ `better-sqlite3` فایل‌های اجرایی
> از‌پیش‌ساخته را برای ویندوز، مک و لینوکس به‌همراه دارد، بنابراین هیچ کامپایلری لازم نیست.
>
> **About SQLite:** the database is an ordinary file at `server/data/shop.db`, created by
> `npm run seed`. `better-sqlite3` ships prebuilt binaries for Windows, macOS and Linux
> (x64 + arm64), so **no compiler or build toolchain is required** on the demo machine.

## 🚀 راه‌اندازی گام‌به‌گام | Step-by-Step Setup

### فارسی

۱. **نصب وابستگی‌ها** — در پوشهٔ اصلی پروژه:

```bash
npm install
```

۲. **(اختیاری) تنظیم متغیرهای محیطی** — پروژه بدون این مرحله هم اجرا می‌شود، اما برای
   تغییر پورت یا کلید JWT:

```bash
cp server/.env.example server/.env
```

۳. **ساخت پایگاه داده و افزودن داده‌های نمونه:**

```bash
npm run seed
```

این دستور جداول را می‌سازد، دو حساب کاربری بالا و ۲۲ محصول فارسی واقع‌گرایانه را اضافه
می‌کند و اطلاعات ورود را در ترمینال چاپ می‌کند.

۴. **اجرای پروژه:**

```bash
npm run dev
```

۵. مرورگر را روی **http://localhost:5173** باز کنید. سرور API روی
   **http://localhost:5000** اجرا می‌شود.

### English

1. **Install dependencies** from the project root:

   ```bash
   npm install
   ```

2. **(Optional) configure environment variables** — the app runs fine without this, but
   to change the port or JWT secret:

   ```bash
   cp server/.env.example server/.env
   ```

3. **Create the database and seed demo data:**

   ```bash
   npm run seed
   ```

   This creates the tables, inserts the two accounts above plus 22 realistic Persian
   products, and prints the credentials to the terminal.

4. **Start both servers:**

   ```bash
   npm run dev
   ```

5. Open **http://localhost:5173** in your browser. The API runs on
   **http://localhost:5000**.

## 🪟 راهنمای کامل ویندوز — از صفر تا اجرا | Windows Setup From Scratch

> این بخش برای کسی نوشته شده که تا به حال با «ترمینال» یا «خط فرمان» کار نکرده است.
> فقط کافی است مرحله‌به‌مرحله جلو بروید. هیچ دانش قبلی لازم نیست.

**«ترمینال» یا «خط فرمان» چیست؟** یک پنجرهٔ سیاه‌رنگ که در آن به‌جای کلیک کردن،
دستور تایپ می‌کنید و کلید `Enter` را می‌زنید. در ویندوز دو نمونهٔ آن وجود دارد:
**Command Prompt** و **PowerShell**. هر کدام را که باز کنید فرقی ندارد؛ دستورهای این
راهنما در هر دو کار می‌کنند.

### گام ۱ — نصب Node.js

۱. به نشانی **<https://nodejs.org>** بروید.
۲. دکمهٔ سبزرنگی که روی آن نوشته شده **LTS** را کلیک کنید (نسخهٔ پایدار و پیشنهادی).
   نسخهٔ **Current** را انتخاب نکنید.
۳. فایل دانلودشده (چیزی شبیه `node-v22.x.x-x64.msi`) را از پوشهٔ Downloads اجرا کنید.
۴. در پنجرهٔ نصب فقط روی **Next** بزنید، تیک «I accept…» را بگذارید و در پایان
   **Install** را کلیک کنید. هیچ گزینه‌ای را تغییر ندهید — تنظیمات پیش‌فرض درست است.
۵. اگر ویندوز اجازه خواست، **Yes** را بزنید. در پایان **Finish** را کلیک کنید.

> اگر در حین نصب گزینه‌ای با عنوان «Tools for Native Modules» دیدید، **لازم نیست**
> تیک آن را بزنید. این پروژه به هیچ کامپایلری نیاز ندارد.

### گام ۲ — باز کردن ترمینال و بررسی نصب

۱. کلید **Windows** روی صفحه‌کلید را بزنید.
۲. عبارت `cmd` را تایپ کنید و روی **Command Prompt** کلیک کنید. (یا `powershell` را
   تایپ کنید و **Windows PowerShell** را باز کنید.)
۳. در پنجرهٔ باز شده این دستور را تایپ کنید و `Enter` بزنید:

```
node -v
```

۴. باید چیزی شبیه این ببینید:

```
v22.14.0
```

۵. حالا این را هم امتحان کنید:

```
npm -v
```

باید عددی مثل `10.9.2` نمایش داده شود.

> ✅ اگر هر دو عدد را دیدید، Node.js درست نصب شده است. به گام ۳ بروید.
>
> ❌ اگر پیام `'node' is not recognized as an internal or external command` را دیدید،
> به بخش [«اگر دستور شناخته نشد»](#-اگر-دستور-شناخته-نشد--command-not-recognized)
> در پایین همین راهنما بروید.

### گام ۳ — آوردن پروژه روی کامپیوتر ویندوزی

**روش الف — دانلود فایل ZIP (ساده‌تر، بدون نیاز به هیچ ابزار اضافه):**

۱. صفحهٔ پروژه را در گیت‌هاب باز کنید.
۲. روی دکمهٔ سبز **Code** کلیک کنید و سپس **Download ZIP** را انتخاب کنید.
۳. فایل ZIP دانلودشده را در File Explorer پیدا کنید (معمولاً در پوشهٔ **Downloads**).
۴. روی آن **راست‌کلیک** کنید و **Extract All…** را بزنید، سپس **Extract** را کلیک کنید.
۵. حالا یک پوشهٔ معمولی دارید. داخل آن بروید تا به پوشه‌ای به نام **`shop-site-js`**
   برسید — پوشه‌ای که داخلش فایل `package.json` و پوشه‌های `client` و `server` را
   می‌بینید. **همین پوشه، پوشهٔ کاری ماست.**

> ⚠️ حتماً فایل ZIP را **Extract** کنید. اگر فقط روی آن دوبار کلیک کنید ویندوز محتوایش
> را نشان می‌دهد ولی فایل‌ها واقعاً استخراج نشده‌اند و دستورها کار نخواهند کرد.

**روش ب — با Git (اگر Git روی سیستم نصب است):**

در ترمینال این دستورها را یکی‌یکی بزنید:

```
git clone https://github.com/AmirInit/uni.git
cd uni\shop-site-js
```

اگر Git نصب نیست، از روش الف استفاده کنید یا Git را از <https://git-scm.com> نصب کنید.

### گام ۴ — باز کردن ترمینال داخل پوشهٔ پروژه

این مهم‌ترین گام است: دستورها **باید** داخل پوشهٔ `shop-site-js` اجرا شوند.

**روش ساده (پیشنهادی) — از طریق نوار آدرس File Explorer:**

۱. با File Explorer وارد پوشهٔ `shop-site-js` شوید (جایی که فایل `package.json` را می‌بینید).
۲. روی **نوار آدرس** بالای پنجره (جایی که مسیر پوشه نوشته شده) یک‌بار کلیک کنید تا
   مسیر آبی و قابل ویرایش شود.
۳. کل متن را پاک کنید، عبارت `cmd` را تایپ کنید و `Enter` بزنید.
۴. یک پنجرهٔ ترمینال باز می‌شود که **از قبل داخل همان پوشه است**. تمام.

**روش دوم — با دستور `cd`:**

اگر ترمینال را از منوی Start باز کرده‌اید، باید خودتان به پوشه بروید:

```
cd C:\Users\نام‌کاربری\Downloads\uni\shop-site-js
```

به‌جای مسیر بالا، مسیر واقعی پوشهٔ خودتان را بگذارید. برای پیدا کردن مسیر واقعی،
مسیر را از نوار آدرس File Explorer کپی کنید.

> اگر پروژه در درایو دیگری است (مثلاً `D:`)، اول نام درایو را بزنید و بعد `cd` کنید:
>
> ```
> D:
> cd D:\projects\uni\shop-site-js
> ```

**چطور مطمئن شوم در پوشهٔ درست هستم؟** این دستور را بزنید:

```
dir
```

اگر در فهرست خروجی نام‌های `package.json`، `client` و `server` را دیدید، جای درستی هستید. ✅

### گام ۵ — اجرای دستورها به ترتیب

هر سه دستور زیر را **به همین ترتیب** و **در همان پنجرهٔ ترمینال** اجرا کنید.

### ⚠️ اگر دستور شناخته نشد | Command not recognized

اگر پیامی مثل یکی از این‌ها دیدید:

```
'node' is not recognized as an internal or external command,
operable program or batch file.
```

```
npm : The term 'npm' is not recognized as the name of a cmdlet...
```

یعنی ویندوز هنوز نمی‌داند Node.js کجا نصب شده است. به ترتیب این‌ها را امتحان کنید:

۱. **پنجرهٔ ترمینال را ببندید و یک پنجرهٔ تازه باز کنید.** ویندوز مسیرهای جدید را فقط
   در پنجره‌های تازه می‌شناسد. در ۹۰٪ موارد همین مشکل را حل می‌کند.
۲. اگر باز هم نشد، **کامپیوتر را یک‌بار Restart کنید** و دوباره `node -v` را بزنید.
۳. اگر همچنان خطا می‌دهد، Node.js احتمالاً کامل نصب نشده است: دوباره به
   <https://nodejs.org> بروید، نسخهٔ **LTS** را دانلود و نصب کنید و در پنجرهٔ نصب
   مطمئن شوید گزینهٔ **«Add to PATH»** فعال است (به‌طور پیش‌فرض فعال است).

**خطاهای رایج دیگر:**

| پیام خطا                                             | معنی و راه‌حل                                                                     |
| ---------------------------------------------------- | --------------------------------------------------------------------------------- |
| `Could not read package.json`                        | در پوشهٔ اشتباهی هستید. با `dir` بررسی کنید و به گام ۴ برگردید                      |
| `EADDRINUSE: address already in use :::5000`          | برنامهٔ دیگری پورت را گرفته یا نسخهٔ قبلی هنوز اجراست. پنجره‌های ترمینال قبلی را ببندید |
| `npm ERR! network` هنگام `npm install`                | اتصال اینترنت قطع است یا فیلتر شده. اتصال را بررسی و دوباره امتحان کنید             |
| صفحهٔ مرورگر خالی است                                 | مطمئن شوید ترمینال `npm run dev` هنوز باز است و خطایی نداده                        |
| محصولی نمایش داده نمی‌شود                             | `Ctrl+C` بزنید، `npm run seed` را اجرا کنید و دوباره `npm run dev` بزنید            |
| تصویر محصولات نمی‌آید                                 | طبیعی است — تصاویر از اینترنت می‌آیند. بدون اینترنت، طرح جایگزین رنگی نمایش داده می‌شود |

## ✨ امکانات | Features

### 🛍️ فروشگاه | Storefront
- شبکهٔ محصولات با تصویر، نام، قیمت به تومان و توضیح کوتاه
- صفحهٔ جزئیات محصول با گالری، موجودی انبار و ضمانت‌ها
- جست‌وجو، فیلتر بر اساس دسته‌بندی، مرتب‌سازی (جدیدترین / ارزان‌ترین / گران‌ترین / نام)
- صفحه‌بندی — وضعیت فیلترها در نشانی صفحه ذخیره می‌شود و قابل اشتراک‌گذاری است

### 🛒 سبد خرید | Shopping Cart
- افزودن، تغییر تعداد و حذف کالا
- محاسبهٔ زندهٔ جمع کل، هزینهٔ ارسال و مبلغ قابل پرداخت
- **کشوی سبد خرید** که از لبهٔ راست (شروع خط در RTL) باز می‌شود
- **ماندگاری سبد:** برای کاربران واردشده در پایگاه داده، و برای مهمان‌ها در `localStorage`
- سبد مهمان هنگام ورود به حساب، به‌صورت خودکار با سبد کاربر ادغام می‌شود
- تعداد هر کالا هرگز از موجودی انبار بیشتر نمی‌شود

### 👤 حساب کاربری | User Account
- ثبت‌نام و ورود با JWT و رمزنگاری `bcrypt`
- ویرایش نام، ایمیل و رمز عبور (تغییر رمز نیازمند رمز فعلی است)
- تاریخچهٔ سفارش‌ها با تاریخ شمسی و مبلغ هر سفارش

### 🛡️ پنل مدیریت | Admin Panel
- افزودن، ویرایش و حذف محصول از طریق یک فرم مودال با پیش‌نمایش زنده
- جدول محصولات با جست‌وجوی هم‌زمان (debounce)
- تأییدیه پیش از حذف
- مسیر `/admin` هم در سمت کاربر و هم در سمت سرور محافظت شده است

| جدول          | ستون‌ها                                                                              |

>

> past orders stay correct even after an admin edits or deletes the product.

## 🔐 امنیت | Security Notes

- رمزهای عبور با **bcrypt** (۱۰ دور) هش می‌شوند و هرگز به کلاینت فرستاده نمی‌شوند.
- احراز هویت با **JWT**؛ توکن در `localStorage` نگهداری و در هدر `Authorization` ارسال می‌شود.
- مسیرهای مدیریتی هم با `protect` و هم با `adminOnly` در سمت سرور محافظت می‌شوند —
  محافظت سمت کاربر فقط برای تجربهٔ کاربری است.
- تمام کوئری‌ها از **prepared statements** استفاده می‌کنند (بدون امکان SQL Injection).
- پیام «ایمیل یا رمز عبور نادرست است» برای هر دو حالت یکسان است تا امکان شناسایی
  ایمیل‌های ثبت‌شده وجود نداشته باشد.
- ورودی‌ها هم در سمت کاربر و هم در سمت سرور اعتبارسنجی می‌شوند.

## ❓ رفع اشکال | Troubleshooting

| مشکل                                          | راه‌حل                                                                    |
| --------------------------------------------- | ------------------------------------------------------------------------- |
| `EADDRINUSE` روی پورت ۵۰۰۰ یا ۵۱۷۳            | برنامهٔ دیگری آن پورت را گرفته؛ آن را ببندید یا `PORT` را در `server/.env` تغییر دهید |
| صفحه خالی است / «ارتباط با سرور برقرار نشد»    | مطمئن شوید `npm run dev` هر دو سرویس (API و WEB) را اجرا کرده است           |
| «سرور در حال اجراست ولی محصولی نیست»           | `npm run seed` را اجرا کنید                                                |
| می‌خواهم داده‌ها را از صفر بسازم                 | `npm run seed:reset`                                                      |
| تصاویر محصولات نمایش داده نمی‌شوند              | طبیعی است — تصاویر از `picsum.photos` می‌آیند. بدون اینترنت، کارت‌ها به‌طور خودکار یک طرح جایگزین رنگی با نام کالا نشان می‌دهند |
| خطای نسخهٔ Node.js                             | Node.js 20.19 یا بالاتر نصب کنید                                           |
